Sistema de registro civil
Descripción
Este proyecto consiste en desarrollar las clases necesarias para un sistema de registro civil. Se busca organizar mejor el funcionamiento del sistema y facilitar el manejo de la información, utilizando Java y algunos patrones de diseño
Primer entregable
Diagrama de clases e implementación en Java.
Proyecto Java
El proyecto está realizado en Java utilizando Gradle. Dentro de la carpeta `src/main/java` se encuentran las clases del sistema, organizadas en la carpeta `model`, y también la clase `Main`, que será la encargada de iniciar el programa.
